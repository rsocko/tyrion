# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, pull request, discussion,
commit, log, or artifact. Use GitHub's **Report a vulnerability** flow on the
repository Security tab. Include the affected revision, impact, and minimal
reproduction details, but do not include credentials, private financial data, session
material, internal service details, or machine-specific paths.

If private reporting is unavailable, contact the repository owner through an existing
private channel and provide only enough information to establish a secure follow-up
channel.

## Deployment status

Automated publication is intentionally disabled. See
[`docs/DEPLOYMENT-TRUST-BOUNDARY.md`](docs/DEPLOYMENT-TRUST-BOUNDARY.md) for the
evidence required before it can be enabled.
